# IgorLo LLM Hub

Общие договорённости для моих проектов. Вход для агента — [AGENTS.md](AGENTS.md). В нём есть короткое правило для любой правки и ссылки на инструкции по конкретным задачам.

## Подключение

1. Добавь [инструкцию клиента](clients/instruction.md) к существующим личным инструкциям Codex в `~/.codex/AGENTS.md` или к пользовательским инструкциям ChatGPT. Для ChatGPT нужен режим с доступом к GitHub или вебу.
2. Добавь тот же указатель в `AGENTS.md` подключаемого проекта. Сохрани рядом локальные требования проекта, включая рабочую ветку, проверки и порядок выпуска.
3. В новом чате попроси назвать SHA хаба, используемый для этой задачи, и применить правило из подходящего тематического файла. После принятия изменения следующий запуск должен прочитать новый SHA. Уже начатая задача продолжает использовать выбранную редакцию.

## Массовое обновление

Добавь GitHub topic `igorlo-hub-managed` проектам, которые участвуют в массовых обновлениях. В локальной переменной окружения `IGORLO_HUB_OWNERS` перечисли через запятую владельцев репозиториев. Для поиска приватных проектов нужна авторизация GitHub с доступом к ним.

Вызови «Обнови зависимости во всех поддерживаемых проектах». [Оркестратор](skills/update-projects/SKILL.md) раздаст независимые репозитории агентам. В сводке будут ссылки на PR, CI и проверенные preview, сведения о покрытии и всё, что требует внимания. Владелец принимает решение о merge и выпуске.

## Изменение правил

Агент показывает в чате предлагаемый текст, примеры применения и исключения. После согласования готовит PR. Правило становится общим после личного ревью Игоря и merge в `main`. [Процесс изменения конвенции](skills/propose-convention/SKILL.md)

## Рефлексия

Скажи «Проведи рефлексию по нашей сессии». Указатель в AGENTS направит агента к [reflect-session](skills/reflect-session/SKILL.md): он прочитает историю, сопоставит ошибки с действующими правилами и проверками, предложит точные изменения и отделит их от новых пожеланий к продукту. Если скилл установлен в клиенте, доступен вызов `$reflect-session`; подключённым проектам достаточно обычной фразы.

Очевидное общее улучшение агент предложит и по ходу работы, продолжая текущую задачу. Сомнительная идея может стать [proposal](skills/propose-convention/PROPOSALS.md): после принятия этой политики агент вправе сам записать безопасный для публикации вопрос в Hub, но внедрение правила требует решения Игоря. Для разбора скажи «Разбери proposal в LLM Hub»; решения и основания останутся в issues. Периодический автоматический разбор не настраивается.
